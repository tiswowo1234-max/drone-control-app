캠퍼스 경비원 보조 드론 — 제어 앱 · 중계 서버 · 위치 인식 병합

## 1. 이번 단계에서 한 일
### 조원 위치 인식 코드 병합
- 조원 저장소 `drone-localization-main`에서 필요한 코드·지도 데이터만 `vision/teammate/`로 복사(조원 동의, 원본은 수정하지 않음).
  - 조원 인쇄 지도는 우리 `map/` 지도와 **같은 파일**(파일 해시 일치)이라 좌표는 m↔cm 단위만 다름.
- 연결 프로그램 `vision/bridge/`: 카메라 영상을 **한 곳에서만** 받아 ① 위치 계산 ② 사건 사진 ③ 앱 영상 중계에 나눠 씀.

### 카메라 2가지 + 앱에서 전환
| 모드 | 카메라 | 위치 계산 (조원 코드) |
|---|---|---|
| `tt_down` | TT 내장 하단 카메라, 흑백 320×240 (UDP 11111) | AprilTag (흑백 전용) |
| `esp32` | 드론에 단 XIAO ESP32, 컬러 (Wi-Fi MJPEG) | 건물·도로 색 정합 + AprilTag |

- 앱 버튼으로 전환(동시 사용 안 함 — 두 결과가 섞이지 않게). 착지·호버링 중에만 전환 가능.
- ESP32에는 조원 실물 시험의 색·조명 보정값을 적용(설정 파일에서 조정).

### 사건 사진 알림 (슬롯 촬영)
- 지도의 사진 슬롯 S1~S4(150×100mm)를 앱 지도에 표시 → 누르면 출동 목표가 됨.
- 드론이 슬롯 위에서 멈추면 드론 위치로 슬롯 영역을 계산해 **똑바로 펴서 잘라** 앱에 알림(목록·지도 표시·사진 확대).
- 320×240에서는 조원의 "사진 찾기"가 거의 동작하지 않아(합성 시험 0~1/120) 슬롯 촬영을 기본으로 함. 사진 찾기는 설정으로 켤 수 있게 남겨 둠.
- AI(LLM) 판별은 꺼 둠(비용·API 키 문제). 켜면 앱에 판별 결과를 보여 줄 준비는 되어 있음.

### 앱
- 사건 알림(배너·진동·배지), 사건 목록·상세, 슬롯 표시·슬롯 출동, 실시간 카메라 영상 화면, 카메라 모드 전환, **이륙 버튼** 추가.

### 서버
- API v0.7: 사건 보고·사진 제공·영상 중계·카메라 모드 전환, 고도 고정(80cm).
- 실제 드론 안전 보강(실물 시험 로그로 원인 확인 후 수정):
  - TT는 **15초 동안 명령이 없으면 스스로 착륙** → 비행 중 5초마다 유지 신호(`rc 0 0 0 0`).
  - TT가 스스로 착륙하면 높이 센서로 감지해 앱에 알림(이전엔 앱이 계속 '비행 중'으로 표시).
  - 출동 목표·현재 위치·이동 구간을 로그에 기록, 목표가 20cm 이내면 "이동하지 않음" 알림.
  - 서버 로그를 `server\logs\server-날짜.log`에 저장.
- 간편 실행 파일: `start_real_drone.bat`(실제 드론), `start_demo_no_drone.bat`(드론 없이).

| 고도 | 태그 인식률 | 위치가 나온 화면 | 위치 오차(중앙값) |
|---|---|---|---|

| 80cm | 20% | 34% | 2.6cm |

## 3. 알아 둘 점 (조작 방법)
- **이륙이 끝나는 데 약 8초** 걸림(이륙 6초 + 80cm 맞추기 2초). 그 사이 누른 착륙은 무시되므로, **호버링을 확인한 뒤 착륙**.
- 드론 방향 센서는 **전원을 켤 때 향한 방향이 0°**. 드론을 정문에 **지도 위쪽을 보게 놓고** 켜고, 켠 뒤에는 돌리지 않기.
- 서버를 켠 뒤 드론 연결까지 수십 초 걸릴 수 있음(드론 부팅·Wi-Fi 연결 중). 서버가 알아서 다시 시도함.
- 연결 프로그램은 **서버를 먼저 켠 뒤** 실행(간편 실행 파일은 자동으로 순서를 지킴).

## 5. 조원이 확인해 주면 좋은 것
- **인쇄 지도·태그·슬롯 사진 준비 일정**: 태그는 반드시 100% 배율(검은 사각형 40mm), 사진은 조원 인쇄 형식(검은 테두리)대로.
- **ESP32 수신 코드**: 받는 방식(HTTP MJPEG인지), 주소·포트, 화면 크기·방향(반전·회전 설정) — 우리 연결 프로그램은 조원 `XiaoCameraSource`(MJPEG)를 그대로 씀.
- 비행 고도에 따른 태그 크기: 80cm에서 인식이 부족하면 태그를 키우는 재설계(조원 `map_layout.py`)가 필요할 수 있음.
