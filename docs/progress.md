## 1. 지금 되는 것
- **앱:**
  - 지도 위 출동(드래그·확인)을 합니다.
  - 이륙·정지·착륙·귀환·비상정지 버튼이 있습니다.
  - 드론 위치·고도·배터리·연결 상태를 표시합니다.
  - 사진 슬롯 S1~S4를 누르면 그 슬롯으로 출동합니다.
  - 사건 알림(배너·진동·목록·사진 확대), 실시간 카메라 영상, 카메라 모드 전환을 지원합니다.
- **서버:**
  - 안전 검사(지도 경계·반경·고도·배터리)를 합니다.
  - 앱 연결이 3초 끊기면 자동 착륙하고, 명령권을 넘겨받게 합니다.
  - mock·sim·real 백엔드, 사건 보고·중복 판정, 영상 중계를 맡습니다.
- **위치 인식:**
  - 조원 코드 사본(`vision/teammate/`)으로 카메라 영상에서 위치·방향을 계산해 서버로 보냅니다.
  - 드론 없이 시험할 수 있는 합성 카메라가 있습니다.
- **실물 대응 (11-21~11-25, 실제 비행 로그로 원인 확인 후 수정):**
  | 문제 | 대응 |
  |---|---|
  | TT 15초 무명령 자동 착륙 | 5초마다 유지 신호 |
  | 드론이 스스로 착륙해도 앱이 모름 | 높이로 감지해 알림 |
  | 고도 오차 | 고도 = 거리 센서 (TT `h`는 30cm까지 틀림) |
  | 기울어진 상태의 위치 오차 | TT 기울기를 위치 계산에 넣음 (합성 오차 5.0 → 1.6cm) |
  | 기수 방향 오차 | 카메라로 잰 방향으로 TT 방향 센서 보정 |
  | 화면 가장자리 렌즈 왜곡 | 화면 가운데 70% 영역 태그만 사용 |
  | 태그 높이 불일치로 위치를 버림 | TT 하단 카메라 시야각 60° → 75.5° |
  | 놓은 위치·방향 오차로 첫 이동이 어긋남 | **초기 정렬:** 첫 이륙 때 가장 가까운 태그 위에서 위치·방향 확정 |
  | 이동 방향 오차 | **출동 방향 바라보기:** 목표 쪽으로 기수를 돌린 뒤 전진 |
  | 고도 | 비행 고도 80 → 50cm |
  | 비행 기록 | 서버·연결 프로그램 로그 파일 저장 |

## 2. 시험 결과 요약
### 드론 없이 (가짜 드론 + 합성 카메라)
이륙 → 슬롯 출동 → 위치 인식 → 사건 알림 → 카메라 전환 → 귀환까지 끝까지 동작합니다.

호버링 위치 오차는 TT 하단 약 3cm, ESP32 약 0.7cm입니다.

**고도별 합성 측정 (TT 320×240)**
| 고도 | 태그 인식 | 위치가 나온 화면 | 오차 |
|---|---|---|---|
| 40cm | 98% | 50% | 1.6cm |
| 50cm | 95% | 66% | 1.6cm |
| 80cm | 19% | 32% | 2.4cm |

→ 50cm로 정했습니다(임시).

### 실제 드론 (사용자 시험)
| 날짜 | 결과 |
|---|---|
| 11-21 | 연결·이륙·호버링·착륙·이동 ✅, 하단 카메라 수신 ✅(왼쪽 위 320×240 잘라 씀, 반시계 90° 회전 보정), 20초 이상 호버링 ✅(유지 신호 후) |
| 11-23 | **S4 사건 알림 성공.** 실제 높이가 TT `h`보다 30cm 높아 태그가 작게 찍힘 → 위치가 드물어 S4를 약 50cm 지나침. 거리 센서 고도로 수정. pitch·roll 부호, 거리 센서 정확도 확인 |
| 11-25 | 이동 중 태그는 보였지만 높이 불일치(비율 1.34)로 모두 버려짐 → 시야각 75.5°로 보정. 명령보다 1.3~1.5배 멀리 가는 현상 관찰(가설, 미확인) |

## 3. 다음 비행에서 확인할 것
1. **시야각 75.5°:** 카메라 높이 ÷ 거리센서 비율이 1.0 근처인지 확인합니다(`vision\logs\bridge-날짜.log`).
2. **초기 정렬:** 앱에 `ALIGN_START` → `ALIGN_DONE`(태그 ID 37)이 오는지 확인합니다.
3. **출동 방향 바라보기:** 서버 로그 `출동 방향 바라보기: … cw/ccw N°` 뒤에 전진만 하는지 확인합니다.
4. **이동 거리 과다 가설:** 명령 거리와 실제 이동 거리를 비교합니다. 맞으면 go 거리 보정을 검토합니다.

## 5. 알아 둘 점 (조작 방법)
- **켜기 전 배치:** 드론을 **정문(빨간 점)에 지도 위쪽을 보게 놓고** 켭니다. 켠 뒤에는 돌리지 않습니다.
- **이륙:** 이륙이 끝나는 데 약 8초 걸립니다. 그 사이 누른 착륙은 무시되므로 호버링을 확인한 뒤 착륙합니다.
  연결 후 첫 이륙에는 초기 정렬이 더해집니다(앱에 '이륙 중'으로 표시).
- **실행 순서:** 연결 프로그램은 서버를 먼저 켠 뒤 실행합니다. 간편 실행 파일은 순서를 자동으로 지킵니다.
